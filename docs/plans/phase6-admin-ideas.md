# Phase 6: Admin powers (Dan, 2026-11-16) — all 10 approved ("the more the better")

Goal: Dan changes the app himself from Admin instead of asking for code changes.

1. **List builder (custom tabs):** add a list (name, icon, colour), choose its fields (Status on/off and its options, seasons, creator/album, rating on/off), lookup source (one of the existing ones or none), order and hide lists for everyone.
2. **Feature switches:** turn on/off for everyone: sign-ups open/closed, friends, feed, comments, reactions, close-call comparisons, walkthrough, install banner.
3. **Announcements:** a banner message to everyone (with an end date).
4. **Edit What's new / Coming soon** from Admin instead of in code.
5. **App text and look:** app name, welcome text on Sign in, accent colour, default theme.
6. **Defaults for new people:** which lists are on, theme, privacy defaults.
7. **Moderation:** delete any comment, see who reacted/commented, remove a post.
8. **Lookup tools:** source health check and a step-by-step "why didn't it find this" log (already in the spec).
9. **Numbers:** members, active this week, titles added, most-rated titles.
10. **Backup:** download a full copy of the database; restore guide.

Not practical: a free-form page builder (any layout, any content). It would be a large app of its own and easy to break.
